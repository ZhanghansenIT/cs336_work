


# 5. Training Loop 

本章节核心是将前序实现的**BPE 分词器**、**Transformer LM 模型**、**交叉熵损失**、**AdamW 优化器**等组件整合为完整的训练流程，同时实现数据加载、断点续训、学习率调度、梯度裁剪等工程化能力，最终完成模型训练、验证与文本生成。 

## 5.1 数据加载（Data Loader）

### 核心需求 
将分词后的一维 token ID 数组转化为批次化(输入-目标)对，即输入为`(batch_size, context_length)`的 token 序列，目标为输入的右移一位序列（预测下一个 token），同时支持内存映射（mmap） 加载超大数据集（避免全量载入内存）。


### 实验步骤

1. 输入校验
接收numpy数组（token IDs）、batch_size、context_length、device，校验：
数组长度 ≥ `batch_size * context_length + 1`（保证能生成至少 1 个批次的输入 - 目标对）
`context_length`为正整数，`batch_size`与硬件显存匹配（低资源端建议8/16，GPU 建议32/64）。

```python
def run_get_batch(
    x: npt.NDArray,  # x 可以认为就是一个 doc文本
    batch_size: int,  # 每次取多少个样本个数
    context_length: int, # 每个样本的长度
    device: str = "cpu"
) -> Tuple[torch.Tensor, torch.Tensor]:

```


2. 随机采样批次
- 一般加载数据集都要支持能够对样本进行打乱顺序, 计算可采样的起始索引范围：`max_idx = len(x) - context_length - 1`，起始索引i需满足`0 ≤ i ≤ max_idx`。

- 随机采样`batch_size`个不重复的起始索引`idxs = np.random.choice(max_idx, size=batch_size, replace=False)`。
- 对每个索引i，截取输入`x[i:i+context_length]`，目标`x[i+1:i+context_length+1]`。


3. 格式转换与设备迁移
- 将采样的输入 / 目标转换为`torch.LongTensor`（token ID 为整数），形状为`(batch_size, context_length)`。
迁移至指定device（CPU/MPS/GPU），返回`(x_batch, y_batch)`。
- 内存映射支持
若数据集过大（如 OpenWebText），通过np.memmap加载而非np.load： 

```python 
start_indices = np.random.choice(max_start_idx + 1, size=batch_size, replace=False)
    
    # 3. 构造输入和目标序列（批量处理，避免循环提升效率）
    # 初始化空数组存储批次数据（ dtype与输入x一致，通常为uint16）
    inputs_np = np.empty((batch_size, context_length), dtype=x.dtype)
    targets_np = np.empty((batch_size, context_length), dtype=x.dtype)
    
    for idx, start_i in enumerate(start_indices):
        # 输入：[start_i, start_i + context_length)
        inputs_np[idx] = x[start_i : start_i + context_length]
        # 目标：[start_i + 1, start_i + context_length + 1)（与输入错位1个token）
        targets_np[idx] = x[start_i + 1 : start_i + context_length + 1]
    
    # 4. 转换为PyTorch LongTensor（token ID需为整数类型）并转移到指定设备
    inputs = torch.tensor(inputs_np, dtype=torch.long, device=device)
    targets = torch.tensor(targets_np, dtype=torch.long, device=device)
    
    return inputs, targets
```

## 5.2 Checkpointing 断点续训实现

### 核心需求
实现模型 / 优化器状态的保存与加载，保证训练中断后能从指定迭代数恢复，保存内容包括：

> 1. 模型的可学习参数（model.state_dict()）；
> 2. 优化器的状态（如 AdamW 的一阶 / 二阶矩估计，optimizer.state_dict()）；
> 3. 当前训练迭代数（iteration）；

可选：学习率调度器状态、验证损失历史等。

### 实现步骤
#### 5.2.1 保存检查点 save_checkpoint
1. 构造检查点字典 ，整合需要持久化的状态，格式为：
```python
checkpoint = {
    "model_state_dict": model.state_dict(),
    "optimizer_state_dict": optimizer.state_dict(),
    "iteration": iteration,
    "lr_scheduler_state": scheduler.state_dict()  # 可选
}
```
2. 写入磁盘

```python
def save_checkpoint(model: torch.nn.Module, optimizer: torch.optim.Optimizer, 
                    iteration: int, out: Union[str, os.PathLike, BinaryIO, IO[bytes]]):
    checkpoint = {
        "model_state_dict": model.state_dict(),
        "optimizer_state_dict": optimizer.state_dict(),
        "iteration": iteration
    }
    torch.save(checkpoint, out)
```

#### 5.2.2 加载检查点 load_checkpoint
1. 读取检查点, 使用torch.load从文件 / 流中加载字典，支持跨设备加载（如 GPU 保存的模型在 CPU 加载）。
```python
checkpoint = torch.load(src, map_location=device)  # map_location指定加载设备
```

2. 恢复状态
- 模型：model.load_state_dict(checkpoint["model_state_dict"])；
- 优化器：optimizer.load_state_dict(checkpoint["optimizer_state_dict"])；
- 迭代数：返回checkpoint["iteration"]，作为后续训练的起始步。
- 关键注意事项
加载前需先初始化模型 / 优化器（与保存时的超参数一致，如d_model、num_heads、lr）；
- 若跨设备加载，需指定map_location，避免显存错误。

```python
def load_checkpoint(src: Union[str, os.PathLike, BinaryIO, IO[bytes]], 
                    model: torch.nn.Module, optimizer: torch.optim.Optimizer) -> int:
    checkpoint = torch.load(src, map_location=next(model.parameters()).device)
    model.load_state_dict(checkpoint["model_state_dict"])
    optimizer.load_state_dict(checkpoint["optimizer_state_dict"])
    iteration = checkpoint["iteration"]
    return iteration

```
